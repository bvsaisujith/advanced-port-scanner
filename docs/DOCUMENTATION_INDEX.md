## ❓ Frequently Asked

**Q: How do I start scanning?**  
A: Double-click `PortXray.exe` and follow [QUICK_START_GUIDE.md](QUICK_START_GUIDE.md)

**Q: What is OS Detection?**  
A: Shows the detected operating system with confidence %. Found in dashboard tab & PDF reports.

**Q: Can I run it without Python?**  
A: Yes! Just run `PortXray.exe`. Python is bundled inside.

**Q: What scan types are available?**  
A: TCP Connect, SYN Stealth, UDP, FIN, NULL, XMAS (see [PORTXRAY_RELEASE_NOTES.md](PORTXRAY_RELEASE_NOTES.md))

**Q: Where are my scan results?**  
A: In the dashboard tabs. Export to PDF via "Export PDF" button.
